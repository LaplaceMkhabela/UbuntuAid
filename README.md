# UbuntuAid - Emergency Response App

A lightweight, low-bandwidth emergency response application for disaster scenarios with custom modal dialogs.

## Features

- 🔴 **Two-button interface** - Simple "I NEED HELP" / "I CAN HELP" dashboard
- 📱 **Low-bandwidth optimized** - Works on 2G/EDGE networks
- 📡 **SMS fallback** - Seamless transition when data fails
- 🎯 **Proximity-based matching** - Connects nearby neighbors
- 💬 **Real-time chat** - WebSocket communication with SMS fallback
- 🗺️ **Location-aware** - Automatic GPS or manual location input
- 🎨 **Custom modal dialogs** - Beautiful, accessible dialogs instead of browser alerts
